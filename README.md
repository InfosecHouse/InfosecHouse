# Infosec House

Welcome to Infosec House! A curated catalog of offensive and defensive cybersecurity tools and resources. Live at **[infosec.house](https://infosec.house)**.

- **1,118 tools** across **45 categories**
- Global search, per-tool pages, community-written cheat sheets, and a free public JSON API

## Contributing

The whole catalog is plain data, so adding a tool, writing a cheat sheet, or fixing a link is a small edit and a pull request you can open right from the GitHub website. See **[CONTRIBUTING.md](CONTRIBUTING.md)**.

Spotted a broken link or want to suggest a tool? Open an [issue](https://github.com/InfosecHouse/InfosecHouse/issues/new/choose), or use the buttons on any tool page.
