Infosec House is a community-maintained catalog of offensive and defensive cybersecurity tools and resources, organized by discipline so you can find what you need and get back to work. It is open source and free to use.

The whole thing is a fast static site generated from plain data in a public repository, which means anyone can help keep it current. Head to the [Contribute](/contribute/) page to add a tool, write a cheat sheet, or report a broken link.
