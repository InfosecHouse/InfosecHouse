Infosec House is community-maintained and open source. The entire catalog is plain data in a public repository, so adding a tool, writing a cheat sheet, or fixing a link is a small edit and a pull request. No web development needed, and you can do it right from the GitHub website.

## Ways to help

### Suggest a tool

Know a tool or resource that belongs here? Open an issue with the name, link, and category, or add it directly in a pull request. Every tool is a few lines of data in its category file, so the change is small. Link to the project's official homepage or repository, not a mirror.

### Write a cheat sheet

Every tool has its own page that can hold a short, practical cheat sheet: install steps, common usage, and links to the official docs. They're plain markdown. On any tool page without one, click **Write the cheat sheet** to open an editor with a template ready to fill in. The existing network cheat sheets ([Nmap](/tools/nmap/), [Wireshark](/tools/wireshark/), [tcpdump](/tools/tcpdump/), [Zeek](/tools/zeek/), [Suricata](/tools/suricata/), [masscan](/tools/masscan/)) show the format.

### Report a broken link

Links rot. If a tool's link is dead, wrong, or the project has moved, open an issue or use **Report a problem** on the tool's page. Fixes are welcome too; just update the entry.

## A few ground rules

> [!NOTE]
> Infosec House is for authorized security testing, defense, research, and education. Keep contributions in that spirit.

- **Legitimate, documented tools only.** No malware droppers, pirated software, or spam.
- **Link to the real source:** the project's own site or repository.
- **Cheat sheets stick to documented usage** and use only example targets in cheet sheets.
- **One topic per pull request** keeps reviews quick.
